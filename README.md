# BJ X Agent Demo

Personal autonomous AI agent built in **exactly 1 hour** using only an iPhone.

### What it does
- Scans RSS feeds (TechCrunch AI, MIT Tech Review + custom)
- Learns writing style from real posts
- Sends proactive "Phoenix Alerts" only when something is relevant
- Generates bilingual (Italian + English) X post drafts in Human Edge style
- Fully controlled via Telegram

### Tech stack
